# Trilhas de conteúdo

Uma **trilha** é o conteúdo de uma stack. O perfil (`meus-estudos/perfil.md`) indica qual usar. O assistente só lê a trilha escolhida.

## Trilhas disponíveis

| Trilha | Stack |
|---|---|
| [dotnet/](dotnet/LEIAME.md) | Backend .NET (C#, ASP.NET Core, EF Core, SQL Server) |

## Como criar uma trilha nova

Crie `trilhas/<nome>/` com:

| Arquivo ou pasta | Para quê |
|---|---|
| `ementas/NN-nome-do-modulo/LEIAME.md` | Uma ementa por módulo: tópicos, o que cobrar e os sinais de resposta ⭐. É a base para gerar perguntas, **não** um banco de perguntas |
| `topicos.md` | Lista fechada de tópicos com as etiquetas (`NN · Nome`) usadas no placar e no histórico |
| `pegadinhas-gabarito.md` | Pegadinhas clássicas com gabarito. **Só para o assistente**; não abra antes de responder |
| `LEIAME.md` | Visão geral da trilha |

Use a trilha [dotnet/](dotnet/LEIAME.md) como exemplo de estrutura e de nível de detalhe.
