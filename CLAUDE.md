# EstudosComplementares

Laboratório de treino para entrevistas técnicas. A **área, a stack e o nível** (Júnior, Pleno ou Sênior) vêm de `meus-estudos/perfil.md`. Tudo em **pt-BR**.

Ao iniciar qualquer sessão, siga **integralmente** [assistente/regras-do-assistente.md](assistente/regras-do-assistente.md): primeiro uso (entrevista de configuração se o perfil não existir), papel de avaliador, fluxo das sessões, comandos (`/sessao`, `/rapido`, `/treino`...; o usuário os escreve dentro de uma frase, ex.: "vamos fazer uma /sessao") e arquivos locais.

Lembretes: o conteúdo fica em `trilhas/<trilha>/` (trilha do perfil); `trilhas/<trilha>/pegadinhas-gabarito.md` é **só para o assistente**; tudo o que é pessoal fica em `meus-estudos/`, fora do git.
